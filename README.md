# md

**A fast Markdown viewer for macOS.**

## Install

1. Download the latest **`md.dmg`** from the [Releases](../../releases) page.
2. Open the DMG and drag **md** into your **Applications** folder.
3. Launch it from Finder or right click a `.md` file and choose Open With -> md

### Optional: the `md` command line

From the app's **Tools ▸ Install CLI** menu, you can install an `md` command so you can
open files straight from the terminal:

```
md README.md CHANGELOG.md
```

## Requirements

- **macOS 11 Big Sur or later**
- **Apple Silicon** (M1 or newer). Intel Macs are not supported.
